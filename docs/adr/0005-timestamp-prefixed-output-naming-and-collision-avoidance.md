# 0005. 导出产物前置时间戳命名与防覆盖物理避让决策

> 状态：部分替代。2026-10-17 用户要求优先按原视频与方案名称排序，将时间戳改为后缀；当前命名仅以 [Output Naming Policy](../../CONTEXT.md#output-naming-policy) 为准。文件名保留原 ADR 标识，便于追溯。

## Context

固定使用原文件名加 `_cut` 难以区分多次导出，产物也缺少方案的语义标签；同名时不能覆盖用户已有文件。

## Decision

原决策采用“前置时间戳 + 可选方案标签 + 原文件名／分段编号”，通过名称表达导出批次和方案。发生冲突时自动递增序号，避免每次导出询问覆盖。

后续把时间戳移至扩展名前，使同一原片及方案更容易聚集排序；防覆盖和保留方案标签的取舍仍有效。具体格式不在此重复维护。

## Consequences

名称可以帮助识别来源和批次，方案记录保留实际产物位置。早期“文件名天然按处理时间排序”的结论只适用于前置时间戳阶段，不适用于当前规则；已有产物不追溯改名。
