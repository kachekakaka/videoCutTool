# 0006. 视频智能降码压缩与画质对比预览架构决策

## Context
在前期版本中，工具专注于基于关键帧的流复制无损裁剪（`-c copy`）。但在实际分发与交流场景中，原始视频码率常高达几十至上百 Mbps，剪辑出的成品体积依然巨大（如几分钟视频达数 GB），难以通过微信、钉钉或网盘分享。用户明确需要“视频降码/体积压缩”能力。
同时，用户在调节降码参数（如 CRF、分辨率）时普遍存在“黑盒焦虑”：担心选择“肉眼无损”或“均衡”后实际画质崩坏，迫切需要在真正耗时导出前“先预览大致效果，对比原画与压缩细节”。

## Decision
经过多轮设计树深度访谈（Grilling）与对开源项目（`ja_workspace`、`f2`、`video-compare`）的充分调研，确立以下架构与交互规范：

1. **工作台分体式模式切换与渐进式参数浮层**：
   - 工作台底栏右侧【立即剪辑】左侧新增分体式模式胶囊：`[ ⚡ 无损秒切 (默认) | 📦 智能降码 ]`；
   - 默认保持无损秒切不变；切换至降码后，主按钮文案联动为 `[🚀 降码导出]`，旁边紧跟 `[⚙]` 图标，点击展开暗黑参数面板；
   - 界面严格遵循渐进式展开，不打扰只想快速无损秒切的用户。

2. **继承 ja_workspace 与 f2 的四档经典预设体系**：
   - 彻底奉行**音频绝对保真铁律**：统一强制采用 `-c:a copy`，绝不重编码音频，消除音质损失与多余耗时；
   - 预设标准化对齐：
     - `high_quality`（高画质）：`libx264 -crf 18 -preset slow`（NVENC 下 `h264_nvenc -cq 19`），画质保留 95%~98%，体积缩减 15%~35%；
     - `balanced`（均衡）：`libx264 -crf 22 -preset medium`（NVENC 下 `h264_nvenc -cq 23`），画质保留 90%~94%，体积缩减 35%~50%；
     - `high_compression`（高压缩）：`libx265 -crf 24 -preset slow`（HEVC NVENC 下 `hevc_nvenc -cq 26`），画质保留 82%~90%，体积缩减 50%~70%；
     - `scale_1080p`（降至 1080p）：限宽 1920 + 高画质编码（`-vf "scale='min(1920,iw)':-2"`）；
     - `custom`：提供 CRF 滑块（18~35）与分辨率限高供高级用户调节；
   - 硬件加速采用 `auto` 策略：优先探测 NVIDIA NVENC，支持则 GPU 秒级压制，不可用则平滑回退至 CPU。

3. **先无损切片合并、再整体压制的单次执行管线**：
   - 当任务既包含分段裁剪又启用了降码时，后台剪辑引擎严格执行：
     1. 首先使用流复制秒切保留片段并拼接出中间无损合并成片；
     2. 仅对该合并成品执行单次整体降码压制（绝不在丢弃的片段上浪费算力，且根治多段独立转码合并可能引入的爆音/不同步）；
     3. 压制成功后自动 GC 清理中间临时无损片。

4. **双模画质对比预览系统（Visual Compression Preview）**：
   - 在降码设置浮层中提供 `[ 🔍 预览画质与细节对比 ]` 按钮，按需触发；
   - **毫秒级抽样生成**：从保留视频区间均匀抽取 3~5 个代表性特征时间戳画面，单帧瞬时提取原图并快速编码出降码帧（耗时 < 500ms）；
   - **双模式自由切换交互**：
     - **卷帘分割模式（video-compare 风格）**：中央垂直滑块左右拖动，左半边原画、右半边降码后，像素级微瑕、噪点与色阶变化一览无遗；
     - **左右并排模式（Simple-FFMPEG 风格）**：双屏并排对齐，直观查看全貌与预估体积对比；
     - 底部提供 1/2/3/4/5 特征场景帧切换与缩放放大能力，彻底消除降码参数选择的不确定性。

5. **方案模型契约与方案中心呈现**：
   - `MediaRetentionPlan` 扩展 `compress?: { enabled: boolean; preset: string; crf?: number; maxHeight?: number; encoder?: string; }`；
   - 方案管理中心卡片以 `⚡ 无损秒切`（青色）与 `📦 压缩: 均衡`（橙紫色）双色徽章鲜明标示，一键批量执行自动分流。

## Consequences
- **一站式闭环体验**：剪辑与体积减负无缝结合，直接复用当前项目的内置 FFmpeg 与异步队列，零额外磁盘开销与安装包膨胀；
- **消除黑盒顾虑**：业界前沿的卷帘/双屏画质对比预览，让用户在正式导出前即可对画质拥有百分之百的把握。
