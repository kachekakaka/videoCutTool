# 0001. Motrix 风格侧边栏布局与方案管理中心架构

## Context
用户要求本工具彻底贯彻 Motrix 的桌面交互质感，并新增三大核心能力：
1. 采用 Motrix 经典左侧竖向导航栏（Sidebar Tabs），将功能划分为工作台（Editor）、方案管理（Plan Manager）和系统设置（Settings）；
2. 建立结构化的“方案管理”中心，支持方案记录（Plan Record）的增删改查（CRUD）、快速回载编辑与一键执行裁剪；
3. 应用程序启动时在可执行文件同级目录自动生成默认配置文件 `config.json`，并持久化输出目录策略与工具链配置。

此外，针对分段卡片排版在加入微调按钮时出现的文本挤压折行（"✓\n保\n留"）问题，必须重构卡片内部栅格与自适应容器。

## Decision
1. **侧边栏多视图路由（Sidebar Tabs）**：
   - 界面整体采用 `[左侧极简导航栏 64px] + [右侧主工作视窗]` 布局；
   - 包含三组一级路由 Tab：
     - `Cutter` (裁剪工作台)：视频播放器、自绘制时间轴与响应式分段卡片流；
     - `Plans` (方案管理)：以卡片或列表表格展示所有历史与未执行的 Plan Record，支持一键执行、载入回工作台、导出 JSON 和物理删除；
     - `Settings` (偏好与配置)：界面化配置输出目录规则、FFmpeg 路径和关键帧安全开关。

2. **方案管理模型与执行生命周期（Plan Lifecycle & Execution Marking）**：
   - 方案以规范 JSON 结构持久化至本地存储目录（`plans/{plan_id}.json`）；
   - 每个 Plan Record 包含：`id`、`sourcePath`、`outputPath`、`segments`、`concatToSingleFile`、`createdAt`、`updatedAt`、`completedAt`、`status` (`ready` | `completed`)；
   - **做好了的方案必须醒目标记**：在方案列表头部展示鲜明绿色徽章 `✔ 已完成剪辑`、输出产物实际路径及完成时间，并提供 `全部 / 待执行 / 已完成` 快速筛选。

3. **配置文件自愈与输出目录策略（Config & Output Policy）**：
   - 启动时自动检查可执行程序所在目录的 `config.json`；若不存在则以默认模板原子化写入；
   - 默认输出目录规则采用 `sub_folder`（原视频同级目录下的 `_cuts/` 专属子文件夹），杜绝文件混淆。

4. **全局 1360px 轴线对齐与分段卡片三段式栅格（Unified Alignment & 3-Tier Card Structure）**：
   - **全局统一垂直对齐轴线**：顶栏 Header、主工作台（播放器与时间轴）、分段卡片流、底部 Dock 状态栏全部绑定统一的 `max-width: 1360px; margin: 0 auto;` 容器，彻底消除左右飘移与边界不齐；
   - **播放器三段式居中**：左侧时间、中间播放核心控制、右侧打标按钮，播放键严格保持物理几何中心居中；
   - **分段卡片固定三段式垂直栅格**（根治文字折行与高低错位）：
     - **行 1（元信息行）**：左侧序号 `#1` + 决策胶囊（`✔ 保留` / `✖ 丢弃`），右侧为片段时长胶囊（`⏱ 30.00秒`）；本行不放时间码，空间充裕，绝不折字；
     - **行 2（独立起止时间行）**：起止时间独占一行，大号等宽纯白字体居中对齐，箭头连接（`00:00.000 ──▶ 00:30.000`），绝对单行，绝不折行；
     - **行 3（操作按钮行）**：底端对齐（`margin-top: auto`），包含【试听】、一体化【保留/丢弃】切换胶囊与【微调切点】步进器；保证同一行所有卡片的操作栏处于绝对同一水平基准线；
     - **等高拉伸**：卡片内部及网格行强制 `height: 100%`，彻底根除不同卡片高低不平的问题。

## Consequences
- 形成了清晰的视图职责划分，工作台专注打标，方案管理专注批量与批处理，设置页专注环境与输出；
- 方案数据结构与 `JA_WORKSPACE` 100% 互通，导出的方案可以直接被 `JA_WORKSPACE` 消费；
- 整个界面在任何屏幕尺寸和窗口缩放比例下均实现像素级整齐对齐。
