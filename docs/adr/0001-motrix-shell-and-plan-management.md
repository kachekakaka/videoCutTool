# 0001. Motrix 风格侧边栏布局与方案管理中心架构

> 状态：保留视图分工与方案管理决策；2026-10-28 清理已过时的配置、字段和布局参数。当前边界见[架构](../架构.md)，术语见 [CONTEXT](../../CONTEXT.md)。

## Context

工作台同时承担编辑、历史记录与环境配置会增加操作干扰；分段卡片曾因信息和按钮挤在同一行而折字、错位。需要让用户持续编辑，同时管理已保存及已执行的方案。

## Decision

- 使用左侧导航切换工作台、方案管理和设置等视图，各自承担编辑、方案操作和环境配置。
- 方案持久保存并可回载；执行结果展示状态、产物位置与完成信息，用户能区分编辑意图和执行结果。
- 顶栏、工作区、片段卡片和底部操作区保持共同对齐关系；元信息、时间与操作分区，避免相互挤压。尺寸与响应式布局由[原型](../prototypes/prototype.html)和当前组件维护。

## Consequences

视图分工使方案管理可独立演进，但仍需共用草稿与后台执行入口。具体字段由 [types.ts](../../src/shared/types.ts)维护，不能从本 ADR 推导接口。

原文中的 `ready | completed` 两态、程序旁实际 `config.json`、`_cuts/` 输出目录及 64px 侧栏均为早期设计，已不作为现行要求。状态、目录分别见 [Execution Status](../../CONTEXT.md#execution-status)、[数据与产物归属](../架构.md#数据与产物归属)和 [Output Directory Policy](../../CONTEXT.md#output-directory-policy)。原文宣称的 JA_WORKSPACE 完全互通与任意窗口像素级对齐没有相应验收依据，不能作为能力承诺。
