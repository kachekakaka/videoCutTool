# 0004. 时间轴切点长按拖拽、关键帧磁吸与悬浮画格预览交互架构决策

## Context
在前期版本中，时间轴切点仅支持点击选中（选中后按 Del 键移除），无法直接在时间轴上拖曳微调位置，也无法对已有切点直接键盘输入指定时间戳。
用户提出明确需求：
1. **切点可直接拖拽调整**，并特别要求**采用长按（Long-press）后拖拽**的交互机制，以便未来平滑移植到移动端/触屏交互设备；
2. **拖拽时不打扰主播放器**：专业用户希望主画面保持当前播放或定位状态，拖拽时像专业剪辑软件一样在切点上方弹出一个**独立的微型悬浮小窗**，实时预览拖动目标帧画面；
3. **精确指定时间**：允许直接打字输入目标时间码精确定位切点。

## Decision
经过多轮设计树追问（Grilling）与领域建模，达成以下核心架构与交互规范：

1. **切点三重手势分流与长按激活机制（Long-press Cut Point Dragging）**：
   - **短按 / 单击（< 300ms）**：选中该切点，时间轴高亮切点线，下方对应的分段卡片自动平滑滚动居中并获得焦点；
   - **快速双击**：切点上方就地（In-place）浮现时间码气泡输入框，支持直接键盘敲入或粘贴时间码，按回车立即生效，按 Esc 取消；
   - **长按（>= 300ms）**：切点顶部菱形旗标产生 Scale 1.25 弹性微放大动效并呈现高亮亮蓝光晕，光标变为抓取手势（`grabbing`），激活拖拽模式并呼出悬浮画格预览小窗。

2. **独立解耦的悬浮画格微型预览（Decoupled Scrub Thumbnail Preview）**：
   - **双轨渲染解耦**：主播放器（`<video>`）与预览小窗彻底解耦。拖拽切点时主播放器不发生 Seek，后台通过专用的轻量级辅助离线渲染单元提取目标时间戳画格，保持主视频播放/停留状态的绝对稳定；
   - **信息集成卡片**：小窗尺寸为 `160x90`（标准 16:9）的暗黑圆角发光卡片，跟随切点水平位移。画格底部集成显示当前毫秒级时间码（`HH:MM:SS.mmm`）；
   - **磁吸与碰撞指示**：当切点靠近关键帧时显示青色微标 `● 关键帧已吸附`；当触碰相邻切点极限时显示红色警告 `已达相邻切点极限`。

3. **数学不变量与关键帧物理吸附（Collision Invariants & Snapping）**：
   - **碰撞不穿透**：由 `RetentionDraft` 领域深模块强制保证：切点严禁穿透相邻切点，且与前后切点及视频首尾必须保持至少 200ms 物理安全间距；
   - **关键帧向左/向近磁吸**：当拖拽距离物理关键帧在 ±8px 视窗范围时，切点自动磁吸贴合该关键帧，协助操作员达成零重编码的无损切割点。

4. **双入口时间码就地编辑（Dual-Entry Timecode Editing）**：
   - 时间轴双击切点唤出就地气泡输入框；
   - 下方分段卡片的入点/出点时间码支持单击直接打字输入；
   - 两处数据完全双向实时联动。

5. **原子历史快照与决策保全（Retention Preservation & Atomic Undo）**：
   - 拖拽松手（`mouseup`）或输入框确认时，原子推入一次 Undo 历史快照，支持 `Ctrl+Z` 一键撤销整个拖拽位移；
   - 移动切点仅改变两侧分段的时长边界，严格保留原分段既有的 `keep` / `discard` 决策。

## Consequences
- **移动端与桌面端交互统一**：长按 300ms 的唤醒机制具备天然的触屏友好性，消除了鼠标普通拖动游标（Seek）与切点位移的误触冲突；
- **沉浸式精细剪辑体验**：悬浮画格预览小窗实现了真正的“无干扰局部寻帧”，主画面不受影响，微操更专业、更自信；
- **领域模型完整性闭环**：`RetentionDraft` 新增切点位移与时间设置方法，保持数据层单向数据流与不可变保全。
