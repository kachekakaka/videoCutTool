# 0004. 时间轴切点长按拖拽、关键帧磁吸与悬浮画格预览交互架构决策

> 状态：交互分离决策有效。2026-10-28 删除易漂移的毫秒、像素与动画参数；本篇不作为跨设备适配的验收证明。

## Context

用户需要拖动和直接输入时间来微调既有切点，同时保留主播放器的播放或停留状态。普通时间轴定位与切点移动必须有清晰的手势区分。

## Decision

- 通过长按激活切点拖动，短按选择切点；时间轴及片段时间提供就地输入入口。
- 拖动目标画格由独立预览提供，不让主播放器跟随拖动定位。
- 切点移动不能穿过相邻切点，保持原片段的保留决定；拖动结束或时间输入确认形成一次撤销操作。
- 关键帧吸附提供定位辅助，不改变导出模式的精度含义。手势、预览样式和阈值见 [Timeline](../../src/renderer/components/Timeline.tsx)，编辑不变量见 [RetentionDraft](../../src/shared/RetentionDraft.ts)。

## Consequences

独立预览降低微调对主播放的干扰，但引入额外画格读取与取消管理；读取成本须遵守[媒体检查边界](../架构.md#媒体检查的耗时边界)。桌面交互选择保留触屏演进空间，不表示移动端已经支持或验证。
