# 0004. 切点拖动采用独立画格预览

> 状态：有效。2026-10-29 收窄为预览与主播放分离的取舍，手势及时间输入细节由组件维护。

拖动切点时需要观察目标画格，同时保持主播放器原来的播放或停留状态。因此选择独立读取目标画格，避免让主播放器随拖动反复定位、改变观看位置或打断播放。

这一选择增加了额外画格读取、取消与过期结果管理，读取成本须遵守[媒体检查边界](../架构.md#媒体检查的耗时边界)。手势、吸附与时间输入见 [Timeline](../../src/renderer/components/Timeline.tsx)，切点编辑不变量见 [RetentionDraft](../../src/shared/RetentionDraft.ts)。
