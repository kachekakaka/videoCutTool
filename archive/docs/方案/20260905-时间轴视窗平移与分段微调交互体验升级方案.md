## 问题陈述 (Problem Statement)

用户在长时间轴粗剪与精细微调作业中，反馈了 5 项影响生产力与操作体感的深层问题：

1. **时间轴放大后末尾不可达（图一）**：当时间轴放大至较高倍数（如 4.5x）时，视窗只呈现视频前半段，因缺乏视窗平移（Pan/Scroll）机制，用户无法通过任何操作滚动或移动到视频后半截及片尾，导致后半段内容无法打标。
2. **时间微调交互单一且步长固定（图二）**：
   - 分段卡片时间码省略了小时位（如 `11:15.094`），长视频无法直观区分小时级跨度；
   - 微调按钮的步长死锁在 `0.1s`（100ms），进行数秒或数十秒调整时需要疯狂连击；
   - 时间码为纯静态文本，无法通过鼠标滚轮进行工业级直接微调。
3. **设置项命名臃肿不够精准（图三）**：底部 Dock 栏的复选框文案为“多保留段合并”和“自适应首帧封面”，词语冗长，缺乏现代专业 NLE 工具的克制感与高级感。
4. **时间轴轨道垂直高度偏大（图四）**：时间轴组件整体高度达 120px 左右（含 64px 画布），挤占了上方核心视频播放器的纵向视野。
5. **试听状态脱节与当前段落高亮缺失（图五）**：
   - 试听某片段后在时间轴任意跳转（Seek），原试听片段依然卡死在“试听中”绿色呼吸态，未自动退出；
   - 分段卡片流未绑定播放游标，播放或跳转到某个分段时，卡片不会自动高亮指示当前所处片段。

## 解决方案 (Solution)

从专业视频剪辑工效学出发，实施全流程交互升级：

1. **时间轴自由平移与末尾全覆盖**：
   - 彻底解除视窗起始偏移限制，支持鼠标滚轮（或 `Shift + 滚轮`、中键/右键拖拽）水平平移时间轴视野，范围完整覆盖 `[0, durationMs]`；
   - 增加游标居中视窗跟随逻辑，放大或播放时自动居中当前播放指针，确保末尾最后一帧 100% 精确可达。
2. **工业级时间码滚轮微调与自选步长体系**：
   - 统一时间码格式补齐小时位：`00:11:15.094`（HH:MM:SS.mmm）；
   - 支持光标悬停滚轮微调：鼠标悬停在 `秒` 位滚动加减秒，悬停在 `分` 位加减分，悬停在 `毫秒` 位加减毫秒/步长；
   - 引入步长多档位选择器：支持 `[0.1s | 1s | 5s | 10s]` 档位切换，微调按钮随动变换为 `[-1s]` `[+1s]` 等。
3. **专业精炼按键命名**：
   - “多保留段合并” ➔ **“多段合并”**；
   - “自适应首帧封面” ➔ **“首帧封面”**。
4. **紧凑扁平化时间轴**：
   - 将时间轴 Canvas 轨道高度由 `64px` 紧凑优化至 **`46px`**，收缩容器内边距，释放约 25~30% 纵向空间给主视频画面。
5. **试听自动解除与当前播放段呼吸跟随**：
   - 用户在时间轴点击跳转或暂停时，立即重置试听状态；
   - 引入 `currentTimeMs` 段落感知，当前播放游标所在的分段卡片自动呈现聚焦激活边框（Active Segment），游标跳到哪一段，卡片即刻跟随高亮。

## 用户故事 (User Stories)

1. 作为一名剪辑师，在将时间轴放大到 4x~8x 时，我希望能用鼠标滚轮或拖拽平滑滚动到视频末尾，以便于对片尾处的切点进行毫米级对齐。
2. 作为一名剪辑师，在调整片段入点出点时，我希望把鼠标悬停在时间码的秒或分上直接拨动滚轮微调，并能自选 1 秒或 10 秒大步长，以便于脱离死板点击、快速调整边界。
3. 作为一名长视频剪辑用户，我希望卡片时间码始终显示小时位（如 `01:12:05.100`），以便于精准掌握长视频绝对时间。
4. 作为一名追求极简视觉的用户，我希望底部选项文案更加精炼紧凑（“多段合并”、“首帧封面”），以便于界面更具专业质感。
5. 作为一名注重屏幕利用率的用户，我希望时间轴轨道更低更紧凑，以便于主视频视窗获得更大的显示面积。
6. 作为一名用户，当我在试听后点击时间轴其他位置时，我希望原试听高亮立即停止，并自动高亮我当前点击的那一段，以便于我清晰知道当前正在查看哪一段。

### 2. 关键设计契约与原型结构

- **时间轴平移算法契约**：
  ```ts
  // 视窗最大偏移量严格封顶于片尾
  const maxViewStartMs = Math.max(0, durationMs - visibleDurationMs);
  const handlePan = (deltaMs: number) => {
    setViewStartMs((prev) => Math.max(0, Math.min(maxViewStartMs, prev + deltaMs)));
  };
  ```

- **时间码滚轮交互结构**：
  ```tsx
  {/* 支持悬停分段滚轮微调的时间码组件 */}
  <div className="flex items-center font-mono text-[11px] bg-black/40 px-2 py-0.5 rounded border border-white/5">
    <span onWheel={(e) => handleWheelNudge(seg.id, 'start', 'hour', e.deltaY)}>00</span>:
    <span onWheel={(e) => handleWheelNudge(seg.id, 'start', 'minute', e.deltaY)}>11</span>:
    <span onWheel={(e) => handleWheelNudge(seg.id, 'start', 'second', e.deltaY)}>15</span>.
    <span onWheel={(e) => handleWheelNudge(seg.id, 'start', 'ms', e.deltaY)} className="text-zinc-400">094</span>
  </div>
  ```

- **当前段落联动高亮判定**：
  ```ts
  // 判定当前播放指针所在段落
  const isCurrentActive = currentTimeMs >= seg.startMs && currentTimeMs < seg.endMs;
  ```

## 测试决策 (Testing Decisions)

1. **测试标准**：
   - 继续恪守纯函数单测体系，不引入重型 UI 框架；
   - 保持既有 `RetentionPlanner.test.ts` 与 `RetentionDraft.test.ts` 9 项单测全部绿标；
   - `npm run build` 全量打包 0 报错。
2. **人工交互验证清单**：
   - **验证项 A（末尾到达）**：载入 30 分钟以上视频，缩放至 4x~8x，滚动滚轮直至时间轴最右端，验证能否平移显示最后几分钟的内容，并将游标拖动到最末帧；
   - **验证项 B（滚轮微调）**：在卡片的时间码上，悬停在秒位滚动滚轮，验证入点/出点按 1 秒步进位移；悬停在毫秒位滚动，验证按毫秒微调；
   - **验证项 C（步长切换）**：切换步长为 1s 或 10s，点击 `[-1s]` `[+1s]`，验证切点移动 1000ms；
   - **验证项 D（时间轴紧凑度）**：验证时间轴高度降低后，主视频播放器区域明显放大，界面更舒展；
   - **验证项 E（试听与高亮跟随）**：试听 #4 分段时，点击时间轴头部切换到 #1 分段，验证 #4 立即停止试听状态，而 #1 分段卡片自动点亮边框。
