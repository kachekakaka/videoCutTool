- **依据**：[AGENTS.md](../../../AGENTS.md)、[CONTEXT.md](../../../CONTEXT.md)、[README.md](../../../README.md)

## 问题陈述 (Problem Statement)

在视频裁剪工作台（CutterPage）当前布局中，存在以下导致纵向空间严重受挤压、信息层次割裂的问题：

1. **自定义合并管理栏冗余且割裂**：在开启“自定义合并”并产生合并组时，分段卡片列表下方会弹出独立的紫黑色管理面板。该面板分为两行（标题行“已自定义合并 1 组文件”与内容行“文件 1：第 1 段 × -> 第 5 段 × 全部拆开”），单独霸占了约 60px 的纵向高度，不仅挤压分段卡片展示区域，还与上方的“选择合并片段”操作按钮在视觉上严重脱节。
2. **顶部工具栏与底部 Dock 栏信息错位**：分段列表标题行右侧常驻了冗长的快捷键文本（空格、C、逐帧、撤销等），在常规分辨率下占据大量横向空间却低频使用；而用户高频关注的“原片/保留/丢弃/切点”核心统计数据却被下放挤在底部 Dock 栏左侧，导致底部操作栏在小窗口或分屏状态下横向拥挤、容易产生折行风险。
3. **底部边界提示常驻霸屏**：“快速无损”模式下的关键帧估算边界提示（约 60~80 个字符的长文本）固定常驻在底部 Dock 栏正下方，硬性占满一整行（约 25~30px 高度），严重拉低了整个编辑界面的垂直可用高度。
4. **底部 Dock 栏自身尺寸偏高偏厚**：Dock 栏外壳内边距过大（`py-2`），右侧“首帧封面”、“存为方案”、“立即剪辑”等主要按钮使用了过大的内边距（`py-1.5`）与大圆角，使得整行总高达到约 52px，视觉感厚重臃肿。

---

## 解决方案 (Solution)

针对上述问题，实施一套高密度的轻量化布局重排方案：

1. **图 1 自定义合并条并入工具栏**：
   - 彻底移除分段卡片列表下方的独立面板，取消“已自定义合并 1 组文件 / 按原视频顺序拼接”标题行；
   - 将具体的合并分组标签（`文件 1：第 1 段 × -> 第 5 段 × [全部拆开]`）直接跟在“选择合并片段”按钮右侧（同一行流式展示），操作入口与合并结果同层就近闭环，纵向直接释放约 60px。
2. **图 3 快捷键与图 4 统计数据位置重排**：
   - 将图 4 统计指标（`原片 / 保留 / 丢弃 / 切点`，带高对比度彩色数值）移至“分段列表”标题行右侧展示；
   - 移除常驻的长串快捷键文本，改为在统计数据右侧提供一个精致的 `⌨️ 快捷键` 帮助图标按钮，鼠标悬停（Hover）弹出半透明快捷键浮层卡片；
   - 底部 Dock 栏左侧不再放置统计指标，释放横向宽度。
3. **图 5 边界提示收纳为微型气泡**：
   - 彻底删除底部 Dock 栏下方单独霸占一整行的静态文本，纵向再节省约 25~30px；
   - 在 Dock 栏“快速无损”按钮旁边，收纳为微型信息图标胶囊（`提前 ~1.55s ⓘ`），鼠标悬停（Hover）或点击时弹出气泡卡片展示完整说明与精确导出提示；精确导出模式下自动隐藏。
4. **底部 Dock 栏降高与按钮瘦身**：
   - Dock 外壳上下内边距由 `py-2`（8px）下调为 `py-1`（4px），外壳圆角微调为 `rounded-xl`；
   - 右侧“首帧封面”、“存为方案”、“立即剪辑”按钮上下内边距统一下调为 `py-1`（高度统一为约 28px，与左侧胶囊组完全齐平对齐），圆角微调为 `rounded-lg`；
   - “立即剪辑”保留鲜艳主题渐变与加粗字重，但高度完全齐平收缩，整栏高度从约 52px 压缩到约 **36px**（净省约 16px）。

## 用户故事 (User Stories)

1. 作为一名视频剪辑用户，我想要自定义合并的分组信息直接展示在“选择合并片段”按钮旁边，以便于我无需在分段列表下方多看一个独立的面板，同时为分段卡片腾出更多垂直显示空间。
2. 作为一名视频剪辑用户，我想要在分段列表顶部直接看到原片、保留时长、丢弃时长和切点数量，以便于我在审阅和微调各分段时一眼掌握剪辑进度与总时长变化。
3. 作为一名视频剪辑用户，我想要快捷键长文本从界面常驻区域移走并收纳在帮助图标内，以便于界面更加清爽干净，且在忘记快捷键时仍可随时悬停查阅。
4. 作为一名视频剪辑用户，我想要底部无损边界提示不再长期霸占整行，而是以微型气泡胶囊的形式随需查看，以便于消除工作台底部的无意义留白。
5. 作为一名视频剪辑用户，我想要底部 Dock 栏及所有操作按钮更加紧凑协调，以便于在有限的屏幕分辨率下获得更大的视频画面与时间轴操作视野。

## 实现决策 (Implementation Decisions)

### 1. 修改模块
- **交互原型**：[prototype.html](../../../docs/prototypes/prototype.html)，同步更新原型对应区域的 HTML 结构与 CSS 样式。
- **核心组件**：[CutterPage.tsx](../../../src/renderer/components/CutterPage.tsx)，重排工作台工具栏、合并片段栏、分段卡片下方区域及底部 Dock 栏结构。

### 2. 交互与布局具体决策

#### 决策一：合并分组条平铺于“选择合并片段”右侧
- 移除原 `outputMode === 'custom' && outputs.some(...)` 在分段卡片下方的容器结构；
- 在 `aria-label="合并片段工具栏"` 内：
  - 左侧保留 `选择合并片段` 按钮（或多选状态下的 `合成一个文件 / 取消选择` 按钮）；
  - 右侧直接追加自定义合并结果流：`outputs.filter(o => o.segmentIds.length > 1)`；
  - 每一组显示为 `文件 N：第 X 段 × -> 第 Y 段 × [全部拆开]` 紧凑小胶囊，支持点击 `×` 移出单段，支持点击 `全部拆开` 批量解散；
  - 容器样式设置 `flex flex-wrap items-center gap-2 text-xs min-w-0`，确保多组时平滑流动。

#### 决策二：分段列表标题行承接统计指标与快捷键 Popover
- 替换原快捷键长文本容器 `hidden md:flex items-center gap-1.5 ...` 为两部分：
  1. **统计指标组**：
     - `原片: [时长]`（中大屏展示）
     - `保留: [绿色时长]`
     - `丢弃: [红色时长]`
     - `切点: [黄色切点数]`
     - 采用等宽字体与醒目语义色，行内紧凑对齐。
  2. **快捷键帮助入口**：
     - 提供一个紧凑的 `button` 或 `div` 胶囊，内含键盘图标与 `快捷键` 字符；
     - 鼠标悬停（`group-hover` 或状态控制）展示精美的半透明深色悬浮卡片，内含空格播放、C 切点、方向键逐帧、Del 删除、Ctrl+Z 撤销等全部完整快捷键指南。

#### 决策三：Dock 栏消除下方文本行，改为快速无损按钮旁气泡
- 移除 `<p role="note" ... data-testid="export-boundary-note">` 整行元素；
- 在快速无损按钮（或模式切换胶囊组）旁边：
  - 当处于快速无损模式时，显示微型气泡胶囊：`提前 ~${(boundaryLeadMs/1000).toFixed(2)}s ⓘ`（或无关键帧时的 `估算中 ⓘ`）；
  - 悬停展示原有的详细原理说明：“按当前关键帧估算，起点最多提前 X 秒；片尾可能扩出，具体余量以产物为准，不保证固定上限。需准确边界请选择精确导出。”；
  - 当切换到“精确导出”或“智能降码”时，该气泡胶囊根据对应模式自动变更或隐去。

#### 决策四：Dock 栏自身瘦身与高度统一
- 外层容器：`px-3 py-1 rounded-xl bg-[#161b22]/95 border border-white/10 shadow-xl backdrop-blur-md`；
- 左侧区域：由于统计指标上移，左侧直接展示“预定保存路径/文件名胶囊”，小窗口下具备最大化的自适应宽度；
- 右侧按钮高度统一定义：
  - “首帧封面”：`px-2 py-1 rounded-lg text-xs`
  - “存为方案”：`px-2.5 py-1 rounded-lg text-xs font-semibold`
  - “立即剪辑 / 降码导出”：`px-3 py-1 rounded-lg text-xs font-bold`，高度统一为 28px，保持视觉对齐；
- 模式切换胶囊与输出方式胶囊保持高度 28px，实现整行各元素严格基线齐平。

## 测试决策 (Testing Decisions)

1. **测试边界与 Seam**：
   - 界面测试 Seam 位于 `src/renderer/components/CutterPage.tsx` 和 `docs/prototypes/prototype.html`；
   - 纯逻辑层（导出计划、关键帧对齐、时间轴换算、合并逻辑）不涉及底层协议变动，不破坏既有数据模型；
2. **验证范围**：
   - 运行 `npx.cmd tsc --noEmit` 验证所有类型无破坏；
   - 运行 `npm.cmd test` 跑通 15 个测试套件、116 项单元测试；
   - 检查常用窗口与窄窗口下的自适应表现，确保文字无重叠截断、按钮无错位，浮层能够正常弹出与收起；
   - 运行 `node scripts/check-docs.cjs` 检查本地文档链接无失效。
