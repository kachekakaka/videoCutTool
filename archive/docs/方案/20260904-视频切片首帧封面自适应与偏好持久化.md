## 1. 背景与问题诊断

在多段视频裁剪导出后，用户发现所有切出的子视频在 Windows 资源管理器中的封面缩略图完全一致，无法根据封面区分各个片段。

### 根本原因
- 许多网络视频（如 Bilibili 下载的 MP4）在主动态视频流外，内嵌了一条静态附加图片流（Stream #0:2: Video: mjpeg, `[attached_pic]`），作为全局视频封面；
- 系统在调用 FFmpeg 进行流拷贝（`-c copy`）时，默认采用了 `-map 0`，导致该静态封面流被无差别复制进每一个导出的切片视频中；
- Windows 媒体缩略图提取器优先抓取 `attached_pic` 作为文件图标，导致即便每个分段的实际画面截然不同，系统呈现的缩略图却千篇一律。

---

## 2. 解决方案与设计

### 2.1 核心策略
1. **流剥离机制**：在执行剪辑命令时，将参数调整为 `-map 0:V -map 0:a?`。精准复制所有动态视频流（大写的 `V` 专门排除静态图片流）和可选音频流，自动剥离内嵌的 `attached_pic`；
2. **偏好设置可控**：支持用户自主选择是否开启该策略，提供设置项并持久化保存至方案文件；
3. **首帧画面自然生效**：剥离固定封面后，操作系统在生成缩略图时会自动回退到视频第一帧有效画面，各个切片视频自然呈现出各具特色的首帧内容。
