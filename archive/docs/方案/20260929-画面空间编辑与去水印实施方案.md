## 问题陈述 (Problem Statement)

用户在针对视频素材进行二次剪辑与加工时，除了在时间轴上剔除片头、片尾或中插广告外，普遍存在强烈的画面空间修饰诉求：
1. **画幅比例重构与去黑边**：原片往往包含多余的上下左右黑边，或需要将 16:9 横屏裁切为 9:16 竖屏以适配短视频平台；
2. **固定水印与台标干扰**：录屏与网络素材常带电视台标、滚动水印或角标，影响观感；
3. **敏感信息遮挡**：画面中的个人账号、人脸或手机号等隐私内容需要快速打码或纯黑遮盖；
4. **交互杂乱与手忙脚乱**：若将时间轴剪辑（波形、切点、保留段卡片）与画面空间编辑（裁切手柄、多遮罩选区）混在同一个屏幕下同时操作，界面极度拥挤、手柄极易误触，用户心智负担过重；
5. **底层物理冲突与环境沉重**：对画面的裁切和去水印在物理上无法通过流复制秒切（`-c copy`）完成；而若直接引入数 GB 的外部 AI 深度学习修复模型，将彻底破坏本项目“50MB 免安装便携秒开”的核心定位。

## 解决方案 (Solution)

贯彻用户“**空间上裁剪是一套，时间上裁剪又是一套，最后都存在同一个方案里面，按照方案执行**”的关注点分离思想，在工作台打造**双模式物理解耦、全局优先作用域、免安装原生滤镜管线与统一方案归一**的完整空间编辑体系：

1. **工作台顶栏双模式解耦交互（Dual-Mode Decoupling）**：
   - 工作台顶栏提供互斥切换胶囊：`[ ⏱️ 时间分段剪辑 ]` ↔ `[ 📐 画面空间修饰 ]`；
   - **时间分段模式**：画面 100% 纯净，零框线零手柄干扰，专注时间轴切点与保留决策；
   - **空间修饰模式**：时间轴静止，主视窗唤出画幅裁切框与去水印工具，分为 `[ 📐 画面裁切 ]`（自由、16:9、9:16、1:1 比例吸附、比例锁与一键还原）与 `[ 🛡️ 去水印与遮罩 ]`（去水印、纯黑遮蔽、马赛克模糊）；
2. **视窗右侧浮动图层抽屉（Floating Inspector）**：
   - 遮罩模式下呼出半透明抽屉，直观管理多个修补方块，点击画布方块与图层列表双向高亮聚焦；
3. **全局优先空间作用域（Global-First Spatial Scope）**：
   - 裁切与遮罩默认全片全局生效，满足 95% 以上去黑边与去台标场景；同时支持特定保留段单独标记覆盖；
4. **免安装轻量级算子与滤镜串联管线（Pipeline Order）**：
   - 坚持零额外体积膨胀，采用 FFmpeg 原生 `delogo`、`drawbox`、`boxblur` 极速算子；
   - Filtergraph 严格遵循：**先原片绝对坐标去水印/遮罩修补，再执行统一画幅裁切**，杜绝位移漂移；
5. **转码自动升轨策略（Transcode Auto-Escalation）**：
   - 包含空间修饰的任务自动升轨为智能转码编码，并在底栏提供明确状态感知；强切回秒切时提示清空空间配置；
6. **多分段合并黑边填充对齐（Letterbox Normalization）**：
   - 单文件合并时自动以首段/全局画幅为母版，不同比例分段居中填充黑边（Letterboxing）；独立导出散片时按各自独立裁切分辨率输出；
7. **统一方案复合归一（Unified Plan Consolidation）**：
   - 时间切割与空间修饰全部统一持久化于同一个 `MediaRetentionPlan`，方案管理中心一键复合执行。

## 用户故事 (User Stories)

### 双模式解耦与视窗交互
1. 作为操作人员，我想要在工作台顶栏一键切换【时间分段剪辑】与【画面空间修饰】两种模式，以便于在剪辑时画面保持纯净、在修饰画面时专注构图，彻底避免误触。
2. 作为操作人员，我想要在切换到空间修饰模式时播放器自动暂停，以便于我在静态画面上高精度拉拽选区。
3. 作为操作人员，我想要无论先进行时间分段还是先进行空间修饰，两者的配置都自动保留在当前草稿中，以便于我灵活安排工作流。

### 画幅裁切（Spatial Crop）
4. 作为操作人员，我想要在画面裁切模式下通过 8 个边角手柄自由拉拽构图框，以便于快速切除影视剧原片的上下左右黑边。
5. 作为操作人员，我想要工具条提供 `[ 16:9 | 9:16 | 1:1 | 原片比例 ]` 快捷吸附胶囊，以便于一键将横屏视频重构为移动端短视频画幅。
6. 作为操作人员，我想要能够开启/关闭等比缩放比例锁（Aspect Ratio Lock），以便于在缩放裁切框时始终保持既定的比例不变形。
7. 作为操作人员，我想要随时点击 `[ ↺ 还原全画幅 ]` 按钮，以便于一键重置回 100% 原始画面，拥有安全的容错机制。
8. 作为操作人员，我想要在拖动裁切框时实时看到裁切分辨率（如 `1080 × 1920 (9:16)`）与中心十字参考线，以便于精确把控导出画面。

### 去水印与遮罩（Watermark Delogo & Mask）
9. 作为操作人员，我想要在去水印模式下直接在视频画面上按住鼠标拖拽，以便于就地圈选出目标台标或水印区域。
10. 作为操作人员，我想要为每个选框独立选择修补类型（`💧 去水印(平滑插值消除)`、`⬛ 纯黑遮蔽`、`🌫️ 马赛克模糊`），以便于分别应对固定角标、敏感账号隐私与背景遮蔽。
11. 作为操作人员，我想要在视窗右侧看到浮动的遮罩图层面板，以便于对画面上的多个修补选框进行列表管理、重命名、切换类型或单键删除。
12. 作为操作人员，我想要点击画面选框时右侧图层列表同步高亮、点击列表项时画面选框同步聚焦，以便于高效定位目标选区。

### 作用域与分段继承
13. 作为操作人员，我希望我拉取的裁切框和水印默认在全片全局生效，以便于不需要为每个分段重复配置相同的黑边与台标。
14. 作为操作人员，我想要在需要时针对特定保留分段标记“独立分段覆盖”，以便于应对多机位素材中部分片段画幅不一致的特殊需求。
15. 作为操作人员，我希望打切点分割视频时，裂变出的两个新分段自动继承原有画幅与遮罩配置；删除切点合并视频时向左吸附继承，以便于状态变迁完全符合直觉。

### 导出升轨与方案管理
16. 作为操作人员，我希望只要我配置了画面裁切或遮罩，底栏与导出引擎自动升轨为智能转码编码（CRF 22），以便于导出的成片正确呈现空间修饰效果且绝对不报错。
17. 作为操作人员，我希望当开启“自动合并为单文件”且包含不同画幅片段时，系统自动执行黑边等比居中填充（Letterbox Normalization），以便于拼接出的成片无拉伸变形、播放器完美兼容。
18. 作为操作人员，我希望未开启合并（独立散落文件导出）时，各保留分段按照各自设定的分辨率独立输出，以便于分别投放到不同规格的社交平台。
19. 作为操作人员，我希望将当前配置存为方案时，时间分段与空间修饰合并存入同一个 `MediaRetentionPlan` 记录，以便于统一管理。
20. 作为操作人员，我希望在方案管理中心卡片上直观看到 `📐 9:16 裁切` 与 `💧 2处去水印` 徽章，并支持一键批量异步执行。

## 实现决策 (Implementation Decisions)

### 1. 架构模块划分与职责隔离
- **前端工作台视图层**：
  - `WorkbenchModeBar.tsx`：顶栏双模式胶囊切换器；
  - `SpatialCropOverlay.tsx`：DOM 级绝对定位交互覆层（8 手柄裁切框、九宫格线、坐标尺寸标签）；
  - `SpatialMaskOverlay.tsx`：多遮罩方块渲染器，支持拖拽移动与拉伸调整；
  - `FloatingLayerInspector.tsx`：视窗右侧悬浮图层抽屉（半透明毛玻璃，支持增删改查）；
- **数据契约与草稿状态机**：
  - 在 `MediaRetentionPlan` 与 `RetentionDraft` 中扩展 `spatialConfig` 字段（包含全局配置与可选的 `segmentOverrides`）；
- **底层转码管线与 Filtergraph 生成器**：
  - `spatialFiltergraph.ts`：纯函数模块，根据原片尺寸、裁切选区与遮罩列表，构建合法的 FFmpeg `-vf` / `-filter_complex` 脚本；
  - `MediaCuttingEngine.ts`：对接 `Transcode Auto-Escalation` 逻辑，当检测到空间滤镜时，无缝切换至降码转码链路。

### 2. 原型提炼之核心数据契约（Data Schema）
来自 [`docs/prototypes/prototype.html`](file:///d:/Projects/litleTools/videoCutTool/docs/prototypes/prototype.html) 的已验证数据模型：

```typescript
export type MaskType = 'delogo' | 'black' | 'mosaic';

export interface SpatialMaskItem {
  id: string;
  name: string;
  /** 基于原视频像素的绝对坐标与尺寸 */
  x: number;
  y: number;
  width: number;
  height: number;
  type: MaskType;
}

export interface SpatialCropBox {
  x: number;
  y: number;
  width: number;
  height: number;
  ratio: 'free' | '16:9' | '9:16' | '1:1' | 'source';
  locked: boolean;
}

export interface SpatialConfig {
  crop?: SpatialCropBox;
  masks: SpatialMaskItem[];
  scope: 'global' | 'segment';
}

/** 扩展现有 MediaRetentionPlan */
export interface MediaRetentionPlan {
  // ... 既有字段 (id, title, sourcePath, outputPath, cuts, segments 等)
  spatialConfig?: SpatialConfig;
  segmentSpatialOverrides?: Record<string, SpatialConfig>;
}
```

### 3. FFmpeg 原生 Filtergraph 串联铁律
底层必须严格遵循确定性的执行次序，避免坐标系统漂移：
1. **修补阶段（原片坐标）**：
   - `delogo=x={x}:y={y}:w={w}:h={h}`：利用边缘像素平滑插值消除固定台标；
   - `drawbox=x={x}:y={y}:w={w}:h={h}:color=black:t=fill`：纯黑遮罩；
   - `boxblur=luma_radius=10:luma_power=2:enable='between(x,...)'` 或局部马赛克子流；
2. **构图裁切阶段**：
   - `crop=w={w}:h={h}:x={x}:y={y}`：在修补后的画面上执行主选区裁切；
3. **黑边对齐阶段（仅限单文件合并）**：
   - `pad=w={targetW}:h={targetH}:x=(ow-iw)/2:y=(oh-ih)/2:color=black`：居中等比加黑边对齐画布。

## 范围外说明 (Out of Scope)

1. **深度学习 AI 消除算法**：不引入 ProPainter、IOPaint、PyTorch 等 GB 级大型 AI 模型，保持 50MB 纯便携定位；
2. **动态运动追踪（Motion Tracking）**：去水印与遮罩仅支持画面固定静态选区，不进行逐帧运动目标追踪打码；
3. **任意多边形或贝塞尔套索**：仅支持标准矩形框，不引入多边形复杂路径遮罩；
4. **音频重编码**：音轨继续严格保持流复制（`-c:a copy`），严禁损伤原声或增加额外转码延迟。
