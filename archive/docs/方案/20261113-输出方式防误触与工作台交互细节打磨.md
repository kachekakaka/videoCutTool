## 问题陈述 (Problem Statement)

在近期工作台紧凑化重构与软件评审中，用户在日常剪辑和配置过程中发现了以下几处交互摩擦点与边界体验缺陷：

1. **自定义合并分组切换缺乏防误触保护**：用户在“自定义合并”模式下精心配置了多个视频合并分组后，若不慎误触了平铺在旁边的“分别输出”或“全部合成”胶囊按钮，系统会立即静默清空所有已建立的分组关联，导致用户的合并配置丢失，造成挫败感。
2. **快捷键浮层层级被外层容器裁切且不支持键盘聚焦**：分段列表标题行右侧的统计指标与快捷键容器设置了 `overflow-hidden`，导致子级的 `⌨️ 快捷键` 悬停浮层卡片无法完整展示、边缘被裁切；同时仅支持鼠标 hover 触发，无障碍及纯键盘操作用户无法通过 Tab 聚焦查看。
3. **系统设置页存在误导性且无实际作用的保存按钮**：设置页顶部存在一个“保存所有配置”按钮，但底层早已实现配置即时自愈自动保存（每次更改即时写入），且该按钮绑定的草稿补丁 `draftPatch` 在常态下为空，点击后无任何新增效果，反而给用户带来“平时改了配置可能没保存”的心理负担。
4. **合并片段工具栏随保留段数量动态跳动**：当有效保留段不足 2 段时，“选择合并片段”按钮被动态隐藏或整行缺乏高度稳定约束，导致时间轴下方区域在切点调整过程中上下位移跳动，影响视觉稳定性。
5. **边界提示信息不够严密与统一**：
   - 快速无损微型气泡提示为“提前 ~X.XXs”，用户不明确该提前量是单段还是全片；
   - 智能降码模式下展开卡片标题仍写作“快速无损边界提示”，概念不贴切；
   - 精确导出模式缺少与前两者形态一致的悬停解释浮层，三种模式的外观交互不对齐。

## 解决方案 (Solution)

针对上述问题，实施一套精准、高可用且遵循现有设计语言的交互与体验打磨方案：

1. **自定义合并模式切换二次确认拦截**：
   - 当当前处于“自定义合并”且存在有效合并分组（`outputs.some(o => o.segmentIds.length > 1)`）时，用户点击切换至“分别输出”或“全部合成”，前置弹出居中警告对话框；
   - 明确告知将清空 N 组自定义合并关系，支持取消（Esc 或点击取消按钮），支持确认后才执行切换，且切换后仍保留撤销（Ctrl+Z）恢复能力。
2. **快捷键容器层级修复与键盘聚焦支持**：
   - 调整右侧容器样式为 `overflow-visible`（文本截断由内层具体元素处理），彻底消除浮层裁切；
   - 快捷键帮助按钮增加 `focus:outline-none focus-visible:ring-1 focus-visible:ring-blue-400`，悬停浮层配合 `group-focus-within:block`，支持 Tab 聚焦即时展开。
3. **设置页保存按钮精简与文案校正**：
   - 彻底移除顶部无实质功能的“保存所有配置”按钮；
   - 将副标题文案精炼为：“配置改动即时生效，当前保存位置见下方路径”，消除用户困惑。
4. **合并片段工具栏保持恒定展示**：
   - “选择合并片段”工具栏保持始终占位常驻；
   - 当保留段少于 2 段时，按钮保持显示但处于 disabled 禁用状态，附带清晰的 tooltip 说明（如“至少需要 2 个保留片段才可合并”），杜绝界面跳动。
5. **导出边界提示文案与交互对齐规范**：
   - 微型气泡提示统一规范为 `最多提前 ~X.XXs ⓘ`；
   - 浮层卡片内明确说明：该提前量为覆盖当前所有保留段的最大值；
   - 智能降码模式下，浮层标题动态变更为“智能降码边界提示”；
   - 精确导出模式对齐提供微型气泡与悬停卡片，详细说明逐帧重编码耗时、起止帧边界规则等。

## 用户故事 (User Stories)

1. 作为一名剪辑用户，当我配置了复杂的自定义合并分组后，想要在不小心点击“分别输出”或“全部合成”时获得明确的二次确认弹窗，以便于防止误操作清空我辛苦设置的分组关系。
2. 作为一名剪辑用户，我想要随时在界面上看到“选择合并片段”按钮的固定位置，以便于在剪辑过程中界面不会因保留段数量变化而上下跳动。
3. 作为一名偏好键盘操作的用户，我想要通过 Tab 键聚焦到快捷键图标并查看速查卡片，且悬浮卡片完整显示不被容器裁切，以便于我不依赖鼠标也能顺畅查阅快捷键。
4. 作为一名应用使用者，我想要在系统设置页面直接获知改动即时生效，而不是面对一个看似需要点击却又不起作用的“保存所有配置”按钮，以便于减轻心智认知负担。
5. 作为一名剪辑用户，我想要在快速无损、智能降码和精确导出三种模式下获得体验一致、文案严谨的边界说明浮层，以便于我清楚了解导出的起止点容差与耗时预期。

  - 工具栏按钮始终保留，通过 `disabled` 状态表达不可用；
  - 边界提示胶囊与悬停卡片文案、标题及精确导出模式对齐。
- **系统设置页组件**：`src/renderer/components/SettingsPage.tsx`
  - 移除无用的 `persistConfig(draftPatch)` 顶部保存按钮；
  - 更新副标题说明文案。
- **交互真源原型**：`docs/prototypes/prototype.html`
  - 同步更新工作台工具栏、边界气泡文案与浮层结构。

### 2. 详细接口与状态决策

#### 决策一：自定义合并切换防误清空确认弹窗
- 在 `CutterPage.tsx` 中定义状态：
  ```typescript
  const [confirmOutputModeSwitch, setConfirmOutputModeSwitch] = useState<'separate' | 'single' | null>(null);
  ```
- 在 `handleOutputMode(mode: OutputMode)` 中判断：
  ```typescript
  const handleOutputMode = (mode: OutputMode) => {
    if (mode !== 'custom' && outputMode === 'custom' && outputs.some(output => output.segmentIds.length > 1)) {
      setConfirmOutputModeSwitch(mode);
      return;
    }
    commitDraftChange(d => d.setOutputMode(mode));
  };
  ```
- 弹窗确认后执行：
  ```typescript
  commitDraftChange(d => d.setOutputMode(targetMode));
  setConfirmOutputModeSwitch(null);
  ```
- 弹窗支持 Esc 键快捷关闭，且在弹窗处于打开状态时挂起全局剪辑快捷键。

#### 决策二：快捷键按钮与无障碍聚焦
- 调整分段列表统计指标容器：
  ```html
  <div className="flex items-center gap-2 sm:gap-3 min-w-0 justify-end overflow-visible whitespace-nowrap text-xs font-mono shrink">
  ```
- 快捷键按钮增加键盘聚焦支持：
  ```html
  <button
    type="button"
    className="flex items-center gap-1 px-1.5 py-0.5 rounded-md bg-white/5 hover:bg-white/10 text-zinc-400 hover:text-zinc-200 text-[11px] font-sans transition-colors focus:outline-none focus-visible:ring-1 focus-visible:ring-blue-400"
    title="查看常用快捷键"
  >
  ```
- 悬浮卡片增加 `group-focus-within:block`，支持键盘 Tab 导航展示。

#### 决策三：边界提示文案与精确导出浮层对齐
- 气泡文本：`最多提前 ~${(boundaryLeadMs / 1000).toFixed(2)}s`。
- 悬停浮层：
  - 标题：`{isCompressMode ? '智能降码边界提示' : '快速无损边界提示'}`；
  - 正文：明确说明为“覆盖所有保留段的最大值”。
- 精确导出气泡：
  - 提供对齐的悬停卡片，标题为“精确导出说明”，说明逐帧精确重编、保留起点不含终点、耗时较长等信息。
